## Open-source libraries I authored

Original open-source projects I designed and built, released under the AWS `aws-samples` organization (MIT-0):

- **[sample-textract-field-memory](https://github.com/aws-samples/sample-textract-field-memory)** — a spatial field-location memory layer that sits after any OCR/extraction step. It learns where named fields appear on recurring layouts, then validates extractions, identifies document types, detects drift, and flags spatial anomalies. Zero dependencies, pure Python. Write-ups: [Medium](https://medium.com/@avneetbansal9815/give-your-document-processing-pipeline-a-memory-and-save-68-on-llm-costs-1619d7b03e61) · [dev.to](https://dev.to/avneet_bansal_a65b3f31fc4/give-your-document-ocr-pipeline-a-memory-59l1).
- **[sample-prompt-correction-memory](https://github.com/aws-samples/sample-prompt-correction-memory)** — self-improving LLM document extraction on AWS. Each human QA correction improves future extractions through few-shot self-healing and deterministic rule graduation — no retraining, no redeployment, and costs decrease over time.
